# report-queue — заметки для Claude Code

Полный план, правила, зафиксированные решения и прогресс по этапам — в корневом файле
`D:\nefu\python\CLAUDE.md` (на уровень выше). **Читать его в начале каждой сессии.**

Кратко:
- Воркеры Celery/RQ и бенчмарки запускаются только в Docker (`docker compose`), не на хосте Windows.
- Хостовый venv: `.venv` (Python 3.13) — для `pytest tests/unit`, генерации графиков и слайдов.
- Документация, докстринги, комментарии — на русском; идентификаторы — на английском.
- Коммиты: `stageN: <что сделано>`, push в `origin main` в конце этапа.
